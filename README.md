<h1 align="center">hakimi</h1>

<p align="center">以 Rust 为核心的本地反代，支持直连 GitHub、Pixiv、AO3、E-Hentai、Hanime、Steam、Poipiku。</p>


## 使用

1. 桌面端可按引导完成自动证书安装和信任
2. 手机端需要手动导出证书和导入用户CA，参考引导信息即可
3. 手机端开启加速后，建议不要使用系统浏览器访问网址，可以采用edg，via这类浏览器
